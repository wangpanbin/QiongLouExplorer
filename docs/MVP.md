# 琼楼寻踪 V0.1 · MVP 范围与里程碑

本文档定义 V0.1 的交付边界，是 `docs/PRD.md` 的执行版本。范围之外的任何功能一律不做，即使技术上很容易。

## 1. 一句话定义

> V0.1 = 一条能在本机、零外部依赖、断网状态下完整跑通的海口骑楼文化探索闭环。

不依赖：高德 Key、大模型 Key、后端服务、MySQL、网络。

| 社区游记、评论、点赞 | 详情页评论 Tab 保留空态 | V0.3 |
| 勋章定义与授勋流程 | 只展示勋章统计数字 | V0.3 |
| WebSocket 实时通信与流式回答 | 消息中心只读已足够体现通信结构 | V0.3 |
| 高德 SDK 与真实路线规划 | 需 Key + SHA1 绑定；改用系统地图 App 导航 | V0.3 |

| GPS 定位与定位权限 | 地图以街区中心作锚点，避免隐私与权限复杂度 | V0.2 |

## 5. 演示脚本（答辩用，约 4 分钟）

1. 启动 App，展示启动页品牌 → 点「开始探索」。
2. 首页：搜索「中山路」，点进结果；返回，点 Banner，进入骑楼老街详情。
3. 详情页：切三个 Tab；点收藏；点「扫码打卡」。
4. 扫码页：使用「手动输入编号」，输入 `1002`，打卡成功 → 跳转详情。
5. 任务页：展示进度 x/y，提交一个任务 → 经验增加。
6. 助手页：问「西天庙建于什么时候？」→ 返回年代；点快捷芯片。
7. 个人中心：三统计更新，进「我的收藏」「我的任务」。
8. 打开飞行模式 → 回详情页，展示离线提示条与正常内容 → 离线页「立即同步」。
9. 首页消息红点 → 消息列表可见系统通知。
10. 收尾：`git log --oneline` 展示 6 个语义提交。

## 6. 技术风险与降级预案

| 风险 | 降级预案 |
|---|---|
| Room 注解处理器与 AGP 9 不兼容 | 升 Room 2.7.x；仍失败则改用 `kapt`/`ksp` 仅处理 Room |
| zxing-android-embedded manifest 冲突 | 使用 `tools:replace`；最终降级为「手动编号 + zxing core 仅解析文本」 |
| 自绘地图点击不准 | Marker 容错半径 48dp；地图页底部另提供「列表」入口 |
| 模拟器无相机 | 演示固定走手动编号路径，PRD 已把它列为正式功能而非补丁 |
